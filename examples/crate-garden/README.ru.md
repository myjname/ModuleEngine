# Ресурсы Crate Garden

[English](README.md) | [Русский](README.ru.md) | [Руководство игры](../../docs/ru/g1-game.md)

Здесь находятся оригинальные низкополигональные модели, текстура палитры,
короткие звуковые эффекты и спокойная зацикленная музыка для G1. Правила игры,
десять оригинальных полей, интерфейс и палитра редактирования принадлежат
[`module-engine-g1`](../../crates/project-g1/README.ru.md). Переиспользуемые
алгоритмы, вывод звука и сохранение данных находятся в отдельных пакетах движка.

Создайте редактируемый проект обычной командой Full Editor:

```powershell
ModuleEngine.exe --new-g1 E:/Games/CrateGarden/project.json
```

Выберите новое имя файла и папку проекта. Обычная транзакция копирует используемые
ресурсы, индексирует их и публикует проект с выбранным профилем Engine. Откройте
JSON в Editor или экспортируйте самостоятельный Player через File/Tools либо
`--export-game`. Редактирование Engine по-прежнему требует полного совпадающего
Full-пакета исходников; сама папка ресурсов не предоставляет эту возможность.

`generate_assets.py` использует только стандартную библиотеку Python. Он
детерминированно создаёт шесть статических glTF-моделей со встроенной геометрией
и общим PNG, а также восемь монофонических PCM16 WAV. Запускать можно из любой папки:

```powershell
python examples/crate-garden/generate_assets.py
```

Существующие ресурсы с другими байтами отвергаются. `--replace` явно пересоздаёт
ресурсы; не используйте его в проекте со своими изменёнными заменами.
`asset-origins.json` содержит пути, размеры и SHA-256 созданных файлов. Все
модели, звуки и мелодия созданы для этого проекта данным скриптом и распространяются
по [лицензии MIT](../../LICENSE) репозитория. Сторонние наборы ресурсов и записи
музыки не требуются.

Простой материал с палитрой намеренно использует поддерживаемую сейчас
статическую непрозрачную геометрию с текстурой. Он не демонстрирует скелетную
анимацию, полный PBR, потоковый звук или мобильную платформу.
