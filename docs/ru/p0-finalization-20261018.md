## Находки и сохранённые неуспешные попытки

**Повторная проверка успешного flight задерживала готовность холодного запуска.** [Cold01](../../outputs/verification/p0-finalization-20261018/cold-01/launch.json) остаётся неуспешной: 46.094/45.0016115 с без итоговой готовности после Stop. Отдельная неуспешная диагностика непригодна для приёмки поставки. Её [анализ 80 событий](../../outputs/verification/p0-finalization-20261018/proof-diagnostic-cold-01/trace-analysis-01.json) показывает повторную проверку ожидающего участника; вложенные накопительные длительности перекрываются. Временные traces [восстановлены](../../outputs/reviews/p0-finalization-20261018/trace-restoration.json) до сохранённого одноразового witness реального участника ожидания успешного того же flight. Точные context/content/build/seal/SDK/generation/artifact проверки, независимые состояния/worker, лимит admission 2 и обычная последующая Cargo/post-seal проверка сохранены. Cold02/03 оставляют собственные исходники/бинарные файлы; они не переименованы в cold04.

**Встроенные корневые окончания строк расходились с sealed shader identity.** Исторические [CLI01](../../outputs/verification/p0-finalization-20261018/windows-cli-01/result.json)/[Profile01](../../outputs/verification/p0-finalization-20261018/engine-profile-01/result.json) остаются неуспешными из-за отсутствующих geometry shaders скопированного Player. [Byte probe](../../work/verification/p0-finalization-20261018/player-shader-binary-probe-01.json) находит реальные встроенные Editor LF и Player mixed-текст при одинаковых checkout/Full байтах; отсутствующий ключ воспроизведён. История появления форм неизвестна. Корневые CRLF-различия теперь незначимы для внутренней identity; include-байты остаются точными/значимыми, авторские файлы и вход DXC не меняются. Отсутствующие sealed shaders никогда не дают доступ к компилятору. Текущие tests/DXC/CLI/GPU/поставки проходят; [контракт](gpu-hlsl.md) сохраняет повторный экспорт согласованной пары/обновление Team и ограничения внутреннего ключа.

**Тесты предполагали ресурсы/политику кэша checkout.** [Windows broad01](../../outputs/verification/p0-finalization-20261018/windows-broad-01/result.json), [broad02](../../outputs/verification/p0-finalization-20261018/windows-broad-02/result.json) и [continuation03](../../outputs/verification/p0-finalization-20261018/windows-broad-continuation-03/result.json) остаются неуспешными: устаревший Full/настройка authoring, отсутствие настоящих ресурсов шаблона, создание junction в sandbox или несовпадающий include root. Отдельные проверенные Full, настоящие ресурсы AssetManifest/export_assets и production resource root сохраняют поведенческие assertions и запреты Team; [точечная junction03](../../outputs/verification/p0-finalization-20261018/windows-junction-03/result.json) проходит на том же артефакте. Текущие полные прогоны заменяют частичные объединения.

Linux [f01](../../outputs/verification/p0-finalization-20261018/linux-f01-broad/result.json) достиг тайм-аута (2400.040989 с, exit -9, без cleanup error), а не был намеренно прерван: Core 108/Custom 15 завершены, Editor без итоговой сводки, следующие 11 targets не запущены. [Отсутствие процессов](../../outputs/verification/p0-finalization-20261018/linux-f01-terminal-absence.json) записано.
