## Поведение и границы

Нативный Vulkan теперь принимает одну отправку `Pending(ticket)` и ровно один раз публикует её неблокирующим опросом точного ticket. Четыре выходные аренды и фактическое завершение GPU потребителя продолжают ограничивать повторное использование. `Busy` не принимает работу; `Ready(Frame)` поддерживает немедленный CPU/software-вывод. Зафиксированные сцена/камера/размеры/revision/tick/происхождение принадлежат завершённым пикселям; pending/ошибка/повтор не создают фиктивный новый кадр. Приём потребляет только принятый префикс одноразовых команд, не повторяемый после последующей ошибки GPU.

Worker опрашивает и публикует завершение до потенциально медленного шага симуляции и вновь после фактической попытки шага, включая rollback. Прежняя одноразовая политика наблюдавшихся столкновений фазы распознаёт тот же закрытый flight identity при пересечении ровно одного успешного tick, зафиксированных epoch/deadline и совпадающих фактическом завершении/запасе времени. Второй шаг/сброс/ошибка/отмена/чужой flight не наследуют коррекцию; уже более поздний срок сохраняется. Fixed 60 Hz-симуляция и целевое планирование показа 120 Hz не меняются. Native JSON не раскрывает закрытый ключ фазы; причинные ограничения устанавливают детерминированные fixtures с настоящим Actor, не предполагаемый native trace.

Панели Scene используют владельцев внутри процесса, ready-почтовые ящики, устранение повторов и ограниченное FIFO ожидания; обход UI сохраняет кэшированные видимые панели и без ожидания удаляет скрытых/закрытых владельцев. Показанные камера/revision/размеры определяют проекцию и новую геометрию попаданий/drop; активный жест сохраняет захваченную камеру. F1 сохраняет готовый результат до ошибки приёма следующего запроса.

Загруженные данные, изображения атласа, ресурсы команд и pipelines/layouts живут до реального завершения GPU. Отмена отбрасывает публикацию, не владение; проверка может ждать следующей отправки/уничтожения backend. Drop рендера передаёт незавершённую работу владеющему фоновому заданию: только оно может ждать собственный fence до 30 с. Завершение приложения сообщает вложенные счётчики producer registered/joined/completed/unconfirmed/failed вместе с освобождением потребителя. Неизвестная ошибка/таймаут/panic/отказ запуска потока удерживают затронутые ресурсы/устройство вместо использования занятой памяти. Явные CPU/software/Glow/PNG-диагностики сохраняют синхронное чтение и отклоняют конфликтующую ожидающую нативную работу. Не добавлены swapchain, несколько отправок производителя, смена частоты/лимита, gameplay/schema-изменение, установка инструментов или замена авторских данных.
