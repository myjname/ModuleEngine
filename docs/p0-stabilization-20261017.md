Their removal does not create an identical extra frame; backlog rejection is transactional and bounded; headless stepping discards render-only batches without GPU effects. Persistent authored **ReadyVariant project recipes** are existing selected controls recreated by `effective_render_controls`/`project_commands` on every actual render, including eligible intermediate poses. Review established no contrary production contract. The aligned Host EN/RU contract now states this distinction; the independent review also covers this documentation. It does not claim that every authored resource command executes once.
