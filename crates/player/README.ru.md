# Самостоятельный Player

[English](README.md) | [Русский](README.ru.md) | [Документация](../../docs/ru/README.md)

Этот пакет содержит общий native UI Player и отдельный executable. У него
нет production-зависимости от Editor или проекта Two Arenas.

Сборка по умолчанию не включает ни одной опциональной реализации. Выбирайте native-пакеты
явно: `ui`, `arpg`, `puzzle`, `vulkan` и `audio`. Окно puzzle использует
`ui,puzzle,vulkan`; ему не нужны ARPG или audio. `ui` включает UI callbacks
только для уже выбранных игровых пакетов. Установка включает нейтральные контракты Core,
привязанный к host контракт Custom и небольшой общий исходный пример вращения;
одни установленные метаданные никогда не активируют авторский модуль.

Приложения совместно используют `composition_at`, `composition_with`, `service_registry`
и UI-функции `run_host`/`run_benchmark_host`. Editor может добавлять source contracts
через callback композиции до синхронизации метаданных. Обычные пути
диспетчеризации Player выбирают UI callbacks исходников по ID contribution.

Экспортированный пакет содержит `player.json` schema 2, авторский проект
format-4, выбранный native executable, необходимые ассеты, заранее собранные Custom
workers и запечатанные Vulkan artifacts, если они используются. Манифест записывает точные
native features, fingerprint данных/API SDK и SHA-256 хеши файлов. Запуск
требует точного совпадения скомпилированных features и точного активного
module/schema/state/SDK lock проекта. Обычное чтение не выполняет миграцию и никогда не заполняет
отсутствующие pins. Валидатор метаданных Editor может проверять меньшую установку,
не выдавая свой бинарник со всеми features за этот выбранный Player.

```powershell
Player.exe
Player.exe --verify-package <package-root> <evidence-folder>
Player.exe --headless-check <package-root> <evidence-folder>
Player.exe --benchmark <evidence-folder>
```

Обычный запуск и native benchmark ищут `player.json` только рядом с
executable. Проверка принимает явный корень пакета, выполняет три настоящих
фиксированных tick и сообщает фактическое состояние и статистику рендера; проверка
с рендером также сохраняет PNG 960×540. Headless-проверка сообщает `frame:null` и
не создаёт renderer или опциональный сервис. Исполнение пакета не использует поиск source
checkout, корень компилятора или policy поставки Editor. Vulkan требует
папку `.spirv` пакета, поэтому отсутствующий artifact вызывает отказ вместо
возврата к компиляции исходников.

Существующий native benchmark сохраняет прогрев из 30 кадров, 120 UI-отсчётов и
120 различных завершённых игровых кадров, требование физических 1920×1080, 45-секундный
watchdog и критерий неизменённой нагрузки с двадцатью врагами. Измеренные данные и
любая невыполненная цель сообщаются прямо; другой проект не удовлетворяет
этому критерию нагрузки только потому, что быстро рендерится.
